# Ultradesign

Ultradesign is an Agent Skill and workflow product for turning a brief into a coherent, implemented, and visually verified frontend, following a design studio's order of work: frame, structure, references as principles, directions, assets, system, motion, composition map, slice, build-out, independent review, final.

- `skills/ultradesign/SKILL.md` is the workflow source of truth. Its prompts (`prompts/01-frame.md` … `13-sharing.md`), references, templates (brief, structure, decisions, deconstruction card, `assets.json`, guard, Storybook), scripts and renderer travel with the skill.
- The skill prescribes; it never offers menus. No numbered choices, multiple choice or yes/no questions in prompts, references or the adapter. Questions are open and one at a time, vague words go down the ladder in `references/questions.md`, and approval is recorded only from the owner's own words.
- `adapters/omp/` is the OMP extension (`ultradesign_checkpoint`, `/ud` owner commands); `scripts/adapters.mjs` installs thin host-specific entry points. Stage and gate IDs in `adapters/omp/workflow.ts` and the prompt file names in `skills/ultradesign/prompts/` change together. `evals/v05/` is the hierarchy evaluation; the rest of `evals/` is the historical v0.1–v0.3 A/B runner.
- `docs/v06-plan.md` is the design behind v0.6; `docs/lessons.md` records the decisions and failures behind the workflow, including the ITSACHAR dry run.
- `README.md` explains installation and invocation.

Use the [Agent Skills reference validator](https://github.com/agentskills/agentskills/tree/main/skills-ref) to run `skills-ref validate skills/ultradesign`. Run `git diff --check` and verify relative Markdown links. Run `bun test`, `bun run test:host`, `node tests/visual-qa-smoke.mjs`, `uv run --script tests/a2ui-tools-smoke.py`, `uv run --script tests/design-tools-smoke.py` and `uv run --script tests/v06-scripts-smoke.py` for the relevant behavior; the renderer needs `uv` and Playwright Chromium, and `animatic` also needs `ffmpeg`. Guard and Storybook template changes also need `node tests/guard-smoke.mjs --app <app>` and `node tests/design-system-preview.mjs --app <app> --out <dir>` against an app with the template's dependencies installed.

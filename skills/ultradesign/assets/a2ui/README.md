# A2UI v1.0 schemas

`v1_0/` holds unmodified copies of `agent_to_renderer.json`,
`catalog_definition.json` and `common_types.json` from
[a2ui-project/a2ui `specification/v1_0`](https://github.com/a2ui-project/a2ui/tree/c26be2dd087b541c46e0296c164ae13bf35f7836/specification/v1_0)
at commit `c26be2dd087b541c46e0296c164ae13bf35f7836`, licensed under the
Apache License 2.0 (Copyright Google LLC). `scripts/a2ui-validate` reads them
offline. Replace all three together when moving to a newer protocol version.

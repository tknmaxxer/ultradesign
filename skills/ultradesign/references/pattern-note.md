# Pattern note

Write one note per reusable pattern. A candidate can start as question, URL, and one observation; expand the selected notes into this shape.

- **Question / user job:** What design decision does this help resolve?
- **Source / observation:** URL, state and private full-page/region PNG paths by CSS width. Record the detail actually seen, not just the source.
- **Study / setup:** Reconstructed slice or trace; the anatomy, tokens, content, states or behavior that make it work.
- **Mechanism / benefit:** How the pattern helps the user do the task.
- **Adaptation:** What should carry over; what changes for project content, identity, system, states and layout; why. After the design contract is written and the study is built, link the recreation made with project data and distinguish it from the adapted route.
- **Fit / constraints:** Where it fails, what remains inferred, and any permissions for material being reused.
- **Proof:** Observable check on the target route; condition and expected result.
